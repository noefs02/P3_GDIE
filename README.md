**Descripción del proyecto**

La aplicación desarrollada es una plataforma web interactiva de videollamadas y mensajería en tiempo real, diseñada bajo una arquitectura descentralizada multi-usuario (Mesh). 
El sistema permite a los usuarios crear salas virtuales, transmitir audio, vídeo y compartir su pantalla de forma fluida. Además, cuenta con un chat integrado que se apoya en modelos de Inteligencia Artificial
(ejecutados localmente en el navegador) para la moderación automática de lenguaje tóxico y la traducción de mensajes en tiempo real. El proyecto actual nace como un complemento de la práctica 1, 
donde se trata una arquitectura simple cliente-servidor para mostrar contenido multimedia, este nuevo proyecto introduce una arquitectura descentralizada (Peer-to-Peer), manejo de flujos multimedia mediante
la MediaStream API y capacidadesavanzadas de procesamiento de lenguaje natural, para crear una "watchparty" de contenido multimedia. Esto incrementa exponencialmente la complejidad técnica y el dinamismo del sistema.
